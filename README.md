# Rescale

An Android app for scaling recipes: adjust by yield, by ingredient, or by factor.

Built with Kotlin, Jetpack Compose (Material 3), Hilt, and a pure-Kotlin `:core:domain` module for the scaling logic.

## Build

```
.\gradlew.bat test assembleDebug lint
```

See `AGENTS.md` for the module layout and `docs/plan.md` for the roadmap.
